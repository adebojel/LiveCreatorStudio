Kebijakan Privasi

Terakhir diperbarui: 17 November 2026

Kebijakan ini menjelaskan bagaimana aplikasi Android LiveCreator Studio menangani informasi saat Anda menggunakan versi aplikasi yang tersedia saat ini (0.5.6).

Ringkasan: berdasarkan source code versi saat ini, aplikasi menyimpan pengaturan dan metadata soundboard secara lokal di perangkat. Source code saat ini tidak menunjukkan layanan akun, backend milik pengembang, atau SDK analitik/iklan. Fitur konektor TikTok LIVE belum terhubung ke antarmuka aplikasi.

1. Informasi yang diproses aplikasi

  • Pengaturan aplikasi: preferensi seperti kecepatan dan pitch text-to-speech, pilihan mulai layanan, dan pengingat disimpan secara lokal menggunakan Android DataStore.
  • Soundboard: ketika Anda memilih file audio, aplikasi menyimpan metadata seperti judul dan URI dokumen serta menggunakan izin akses URI yang diberikan Android. File audio tetap berada pada lokasi yang dipilih pengguna; aplikasi tidak mengunggahnya ke server pengembang berdasarkan implementasi saat ini.
  • Teks untuk text-to-speech: teks yang Anda masukkan diteruskan ke mesin TextToSpeech yang tersedia/terpilih pada perangkat. Mesin TTS atau penyedia Android yang Anda gunakan dapat memiliki kebijakan pemrosesan dan jaringan sendiri. Periksa pengaturan dan kebijakan penyedia mesin TTS tersebut.
  • Informasi layanan: Android dapat menampilkan notifikasi layanan foreground/media saat Anda menggunakan pemutaran atau fitur audio latar belakang.

2. Pengumpulan dan pembagian data

Dalam source code versi 0.5.6 yang ditinjau, tidak ditemukan implementasi akun pengguna, server pengembang untuk mengumpulkan data, analitik, atau iklan. Aplikasi tidak menyatakan mengirim data pribadi ke pengembang. Perilaku aplikasi dapat berubah pada versi mendatang; perubahan material akan dijelaskan melalui pembaruan kebijakan ini.

Jika Anda membuka tautan eksternal (misalnya GitHub), situs tersebut memproses data sesuai kebijakan privasinya sendiri. Mesin TTS, sistem operasi, dan aplikasi pihak ketiga juga tunduk pada kebijakan masing-masing.

3. TikTok LIVE dan layanan pihak ketiga

Kontrak antarmuka provider LIVE dan dependensi evaluasi tersedia dalam source code, tetapi konektor TikTok LIVE runtime belum diaktifkan/diintegrasikan ke alur aplikasi versi ini. Karena itu, kebijakan ini tidak mengklaim bahwa data akun TikTok atau event LIVE sedang dikumpulkan atau diproses oleh aplikasi. Jika integrasi resmi ditambahkan kelak, kebijakan akan diperbarui sebelum fitur tersebut dirilis.

4. Izin dan kontrol pengguna

Aplikasi meminta izin Android yang berkaitan dengan notifikasi dan layanan media latar belakang, serta menerima akses file audio melalui pemilih dokumen Android saat Anda memilih file. Anda dapat mengelola izin melalui pengaturan Android. Menghapus item soundboard dari aplikasi menghapus entri pustakanya; pengelolaan file sumber tetap mengikuti lokasi penyimpanannya.

5. Penyimpanan, keamanan, dan retensi

Pengaturan dan metadata yang disebutkan di atas disimpan di penyimpanan aplikasi pada perangkat. Perlindungan data juga bergantung pada keamanan perangkat, versi Android, dan pengaturan pencadangan perangkat. Aplikasi dikonfigurasi dengan pencadangan Android dinonaktifkan. Menghapus data aplikasi atau mencopot pemasangan dapat menghapus data lokal aplikasi dan mengakhiri akses yang terkait.

6. Privasi anak

Aplikasi ini merupakan alat bantu kreator dan tidak dirancang khusus untuk anak-anak. Jika Anda adalah orang tua/wali dan memiliki pertanyaan tentang penggunaan aplikasi oleh anak, hubungi pengembang.

7. Perubahan kebijakan

Kebijakan ini dapat diperbarui ketika fitur, dependensi, atau praktik pemrosesan data berubah. Tanggal pembaruan akan dicantumkan di bagian atas halaman. Silakan periksa halaman ini secara berkala.

8. Kontak

Untuk pertanyaan atau permintaan terkait privasi, hubungi livecreatorstudio.official@gmail.com.

Dokumen ini menjelaskan implementasi source code yang ditinjau untuk versi 0.5.6 dan bukan nasihat hukum. Pernyataan ini harus ditinjau kembali sebelum rilis fitur online atau pengumpulan data baru.
