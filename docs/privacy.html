Kebijakan Privasi

Terakhir diperbarui: 17 November 2026

Kebijakan ini menjelaskan pemrosesan informasi oleh aplikasi Android LiveCreator Studio versi 0.7.3 dan situs informasi proyek.

Ringkasan: versi 0.7.3 berfokus pada audio lokal. Pengaturan, metadata soundboard, audio impor, aturan Actions & Events yang tersedia pada versi aplikasi, dan data layanan lokal disimpan di perangkat. File audio impor dan paket yang dipasang disimpan di penyimpanan privat aplikasi. Versi 0.7.3 menyediakan ekspor/pemulihan arsip lokal yang dimulai sendiri oleh pengguna melalui pemilih file Android. Aplikasi mengakses internet untuk mengunduh paket suara yang dipilih. Source yang ditinjau tidak menunjukkan akun pengguna, backend pengembang, analitik, atau SDK iklan. Integrasi TikTok belum aktif.

1. Informasi yang diproses di perangkat

  • Pengaturan: preferensi aplikasi seperti pengaturan TTS dan status/pilihan fitur disimpan secara lokal menggunakan Android DataStore.
  • Soundboard: metadata item (judul dan URI file) disimpan secara lokal. File audio yang dipilih melalui Android document picker disalin ke penyimpanan privat aplikasi agar tetap tersedia jika penyedia dokumen memindahkan atau mencabut file asli.
  • Paket suara: ketika pengguna mengunduh paket, arsip atau file audio diambil melalui HTTPS dari sumber katalog yang ditinjau (Kenney, OpenGameArt, dan SFXMint), lalu audio dan catatan lisensi disimpan di penyimpanan privat aplikasi. Paket yang sudah terpasang dapat diputar offline.
  • Text-to-speech: teks yang dimasukkan diteruskan ke mesin Android TextToSpeech yang tersedia/terpilih pada perangkat. Pemrosesan teks dan kemungkinan koneksi jaringan bergantung pada mesin TTS pihak ketiga yang dipilih pengguna.
  • Audio latar belakang dan Floating Control: Android mengelola notifikasi media/foreground service. Floating Control menggunakan izin “Tampil di atas aplikasi lain” hanya jika pengguna mengaktifkannya.

2. Koneksi jaringan dan penyedia eksternal

Aplikasi menggunakan koneksi internet untuk mengambil paket suara dari domain sumber yang tercantum dalam katalog. Server sumber dapat menerima informasi teknis standar dari permintaan jaringan, seperti alamat IP, waktu permintaan, user-agent, dan header koneksi. Pengembang tidak mengendalikan kebijakan privasi atau retensi server tersebut. Aplikasi juga dapat membuka tautan GitHub dan situs proyek; layanan tersebut tunduk pada kebijakan penyedianya.

3. Pengumpulan, akun, dan pembagian data

Versi 0.7.3 tidak memerlukan akun LiveCreator. Fitur lokal tidak mengirim file audio impor, teks TTS, pengaturan, atau arsip cadangan ke server LiveCreator. Cadangan dibuat hanya ketika pengguna memilih ekspor dan disimpan ke lokasi yang dipilih pengguna; pemulihan membaca arsip yang dipilih pengguna. Koneksi unduhan paket suara tetap menghubungi server sumber paket dan dapat memproses informasi jaringan standar. Pernyataan ini berlaku untuk versi 0.7.3 yang dirilis dan harus ditinjau ulang saat fitur online baru ditambahkan.

4. TikTok dan layanan LIVE

Versi 0.7.3 belum mengintegrasikan TikTok Login Kit, Share Kit, atau konektor TikTok LIVE runtime. Aplikasi saat ini tidak mengintegrasikan Login Kit, Share Kit, Content Posting API, Webhooks, atau konektor TikTok LIVE runtime. Aplikasi tidak meminta kredensial TikTok dan tidak mengklaim mengumpulkan komentar, gift, follow, like, share, atau event LIVE. Jika integrasi resmi ditambahkan pada versi mendatang, kebijakan ini akan diperbarui sebelum fitur dirilis untuk menjelaskan data, tujuan, dasar pemrosesan, penyimpanan, dan kontrol pengguna yang relevan.

5. Izin dan kontrol pengguna

Izin Android digunakan untuk fungsi yang relevan, termasuk internet untuk unduhan paket, notifikasi/foreground media, dan overlay opsional. Pemilihan file audio dilakukan melalui document picker Android. Pengguna dapat mengelola izin melalui Pengaturan Android dan dapat menonaktifkan Floating Control. Paket suara dan audio impor disimpan pada direktori privat aplikasi.

6. Penyimpanan dan penghapusan

Data lokal disimpan selama aplikasi terpasang dan sampai pengguna menghapus item/data aplikasi atau mencopot pemasangan. Menghapus data aplikasi atau uninstall dapat menghapus pengaturan, metadata, paket suara, dan audio impor yang tersimpan secara privat. Cadangan manual ZIP versi 0.7.3 dapat berisi pengaturan aplikasi, preferensi Floating Control, metadata soundboard, serta audio impor yang disertakan. Arsip berada pada lokasi yang dipilih pengguna dan dapat berisi data privat; pengguna bertanggung jawab menjaga keamanan file tersebut. Data aplikasi yang belum diekspor dapat hilang ketika data aplikasi dihapus atau aplikasi dicopot. Server penyedia paket suara memiliki kebijakan log dan retensinya sendiri.

7. Anak-anak

Aplikasi ini merupakan alat bantu kreator livestream dan tidak dirancang khusus untuk anak-anak. Orang tua/wali dapat menghubungi pengembang jika memiliki pertanyaan mengenai privasi.

8. Perubahan kebijakan

Kebijakan ini diperbarui ketika fitur, dependensi, atau praktik pemrosesan data berubah. Tanggal revisi dicantumkan di bagian atas halaman. Pengguna disarankan memeriksa halaman ini setelah pembaruan aplikasi.

9. Kontak

Pertanyaan atau permintaan terkait privasi dapat dikirim ke livecreatorstudio.official@gmail.com.

Dokumen ini menjelaskan praktik yang dimaksudkan untuk versi 0.7.3 berdasarkan implementasi proyek yang ditinjau, bukan nasihat hukum. Pengguna sebaiknya meninjau izin mesin TextToSpeech Android dan penyedia paket audio pihak ketiga yang dipilih. Peninjauan hukum profesional tetap diperlukan sebelum distribusi komersial atau penambahan pemrosesan data online.
