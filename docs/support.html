Pusat Bantuan

Panduan singkat untuk memasang, menggunakan, dan melaporkan masalah LiveCreator Studio.

Bagaimana cara memasang aplikasi?

Buka halaman Unduh & Rilis, pilih rilis terbaru, unduh APK, lalu ikuti konfirmasi keamanan Android. Ingat bahwa APK saat ini adalah build debug untuk pengujian.

Bagaimana menggunakan text-to-speech?

  1. Buka tab TTS di aplikasi.
  2. Masukkan teks yang ingin dibacakan.
  3. Gunakan preview atau kontrol baca.
  4. Sesuaikan kecepatan dan pitch bila diperlukan.

Suara dan bahasa bergantung pada mesin TTS yang tersedia di perangkat.

Bagaimana menambahkan audio soundboard?

  1. Buka tab Soundboard.
  2. Pilih opsi impor audio.
  3. Pilih file audio melalui pemilih dokumen Android.
  4. Gunakan tombol putar atau stop pada item yang diimpor.

Pastikan Anda memiliki hak untuk menggunakan audio tersebut.

Apakah integrasi TikTok LIVE sudah aktif?

Belum. Konektor LIVE dan integrasi Login/Share Kit TikTok belum aktif pada versi aplikasi saat ini. Kami akan memperbarui halaman status ketika integrasi benar-benar siap dan telah diuji.

Bagaimana melaporkan bug?

Buka GitHub Issues dan sertakan versi aplikasi, model perangkat, versi Android, langkah reproduksi, serta hasil yang diharapkan. Jangan unggah Client Secret, token akses, kata sandi, atau informasi akun.
