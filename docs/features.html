Fitur LiveCreator Studio

Satu studio ringan untuk membantu kreator mengelola audio pendamping livestream melalui perangkat Android. Keterangan di halaman ini membedakan fitur yang sudah tersedia dari rencana pengembangan.

Tersedia di source saat ini

Text-to-speech lokal

Menggunakan Android TextToSpeech yang terpasang di perangkat. Pengguna dapat memasukkan teks, mendengarkan preview, mengatur kecepatan dan pitch, serta menghentikan pembacaan.

Tersedia di source saat ini

Soundboard lokal

Impor audio melalui Android document picker, simpan metadata pustaka, lalu putar atau hentikan audio menggunakan Media3 dan kontrol media Android.

Tersedia di source saat ini

Audio latar belakang

Layanan foreground dan notifikasi media membantu menjaga kontrol pemutaran saat pengguna berpindah aplikasi, sesuai batasan sistem Android.

Tersedia di source saat ini

Picture-in-Picture

Panel ringkas status aplikasi dapat digunakan pada perangkat Android yang mendukung mode Picture-in-Picture.

Belum aktif

Konektor TikTok LIVE

Penerimaan event LIVE belum terhubung ke alur runtime aplikasi. Jangan menganggap pembacaan komentar, gift, follow, atau event lain sudah berfungsi.

Belum aktif

Login dan Share Kit TikTok

Login TikTok dan berbagi konten ke TikTok belum diintegrasikan ke aplikasi. Tidak ada izin TikTok yang diminta oleh versi ini.

Kompatibilitas

Aplikasi Android menggunakan minSdk 26 (Android 8.0 Oreo) dan dibangun dengan Kotlin serta Jetpack Compose. Fitur TTS bergantung pada mesin TextToSpeech yang tersedia di perangkat.
