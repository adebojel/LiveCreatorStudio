Produk yang tercantum dalam dokumentasi publik TikTok

Dokumentasi publik TikTok for Developers yang ditinjau mencantumkan produk seperti Login Kit, Share Kit, Content Posting API, Display API, Research API, dan Embed Videos. Katalog publik tersebut tidak mendokumentasikan produk API umum untuk mengambil event LIVE (chat/gift/follow) secara real-time. Karena itu kami tidak akan menyebut konektor pihak ketiga atau reverse-engineered sebagai API resmi TikTok.

Gerbang sebelum integrasi resmi Android

  • Pilih produk dan scope resmi yang benar-benar sesuai dengan fungsi yang ingin dibuat.
  • Untuk Login Kit, authorization code ditukar menjadi token di backend; Client Secret dan refresh token tidak boleh disimpan di APK atau repository.
  • Pedoman review TikTok menyebut aplikasi mobile harus tersedia di Google Play atau Apple App Store; Android juga memerlukan package name dan signing information.
  • Aplikasi yang masih dalam tahap pengembangan/pengujian tidak memenuhi kriteria review yang dipublikasikan.
  • Pengajuan harus menyertakan demo end-to-end dari integrasi nyata, bukan mockup.

Keputusan proyek saat ini

Distribusi Google Play masih ditunda. Karena itu kami tidak mengajukan review Android, tidak membuat URL Play Store palsu, tidak mengarang fingerprint signing, dan tidak menaruh Client Secret/token di GitHub. Pekerjaan berikutnya dibatasi pada dokumentasi, pemetaan API yang benar-benar tersedia, dan persiapan arsitektur aman sampai prasyarat platform dipenuhi.
